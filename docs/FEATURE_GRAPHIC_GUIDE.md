# Play Store Graphics Guide

**Icon** → 512 × 512 px PNG, ≤ 1024 KB  
**Feature Graphic** → 1024 × 500 px JPG or PNG (no alpha).  
**Screenshots** → 1080 × 1920 px; 2–8 required.

Visual tone: calm gradients (#0B1020 → #1B2B6D) and gentle light accents.  
Include affirmation text overlays for marketing (e.g., “Gratitude is Power.”).
