# Spark™ Accessibility Statement

Spark™ strives for accessibility by default.

- Supports Android Dynamic Type and system font scaling (up to 200%).
- All interactive elements labeled for TalkBack.
- Color contrast ratio ≥ 4.5 : 1 for text on backgrounds.
- Large tap targets (≥ 48 dp).
- Visual cues never rely solely on color.
- Continuous testing performed using Android Accessibility Scanner.

If you encounter barriers, contact: lamontlabs@proton.me
